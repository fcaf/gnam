# GNAM · Gusti Nostri, Archivio Multimediale

Il ricettario della famiglia: video, appunti e foto diventano schede ordinate da cucinare e stampare.

- Acquisizione da **link** (YouTube, TikTok, Facebook, Instagram, siti di ricette), **video caricati**, **foto** di appunti e libri, **testo** incollato o **scrittura diretta**
- Lettura, trascrizione e traduzione automatica con **Google Gemini**
- Schede con categoria, tag, porzioni ricalcolabili, tempi, difficoltà, costo, ingredienti per sezioni, procedimento a passi, note e fonte
- Ricette **condivise** o **private**, preferite e voti per persona
- **Lista della spesa** condivisa, generata dalle ricette
- **Stampa** A4 con foto o scheda A5 per il raccoglitore, anche in PDF
- Accesso con **link magico o codice email**, solo su invito; app installabile sul telefono (PWA)

Stack: HTML, CSS e JavaScript senza compilazione · Supabase (Postgres, Auth, Storage, Edge Functions) · GitHub Pages · Gemini API.

Installazione passo per passo: **[GUIDA-INSTALLAZIONE.md](GUIDA-INSTALLAZIONE.md)**.
Senza configurazione (`js/config.js` vuoto) l'app parte in modalità dimostrativa con dati locali.
